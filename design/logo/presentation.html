What we heard

The brief

An open-source desktop screenshot tool for Windows, Linux and macOS. Its one unusual trick: select a region once, press a key for every capture, and the shots are appended into a single tall image. Used by developers, QA and documentation people; the GitHub README and the system tray are its main stages.

precisequickunobtrusivejoined-up

Reads at 16 px in a monochrome tray, works in one colour, says 'capture + join' without a camera, scissors or lens.

Final design

Seam

One tall frame whose middle bar is a running stitch: two shots joined by the selection marquee itself.

  • The dashed line is both the selection marquee and the stitch, so the mark says capture and join in one shape
  • A tall frame hints at the tall image the tool produces
  • Built on an 8-unit grid with one outer radius; a 3-stitch cut keeps it crisp at 16 px
  • Seam Blue with Thread Yellow stitches is ownable next to ShareX's flat blue, Snagit's red and Greenshot's green
