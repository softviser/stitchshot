# StitchShot — logo brief (v1, assumptions stated)

Name: StitchShot (one word, capital S twice). Maker: Softviser. Open source, MIT.
What: desktop screenshot tool for Windows, Linux, macOS. The one thing nobody else does well:
stitch several captures of one region into a single tall image (lists, long pages, mixed pieces).
Audience: developers, QA, support and documentation people; GitHub README and tray icon are the main stages.
Adjectives: precise, quick, unobtrusive, joined-up (stitched), honest/open-source.
Competitors and their marks: ShareX (blue arrow glyph), Greenshot (green G), Flameshot (flame),
Snagit (red S), Lightshot (feather), Snipping Tool (scissors), CleanShot, Shottr, Monosnap.
Clichés to avoid: camera, lens/aperture, scissors, flash, pin, corner-bracket viewfinder on its own, magnifier.
Constraints: must read at 16 px in the tray (monochrome on Windows), as a 256 px app icon, in a README header
and GitHub social preview; one colour must work. Existing equity: a blue (#2B6CB0) rounded tile with three
white bars, one day old, free to replace. Decision-maker: Hakan (Softviser).

## Word map
stitch -> seam, running stitch (dashes), thread, suture, zigzag, join, patch, continue
shot   -> capture, frame, selection marquee (dashes!), crop, snapshot, viewfinder
tall   -> strip, ribbon, scroll, column, receipt, filmstrip
append -> plus, chain, link, overlap, next
Intersection: the running stitch and the selection marquee are the same drawing: a dashed line.
Second intersection: frames that overlap/interlock = frames joined.

## Concept longlist (one sentence each)
1. Seam — one tall frame whose middle bar is a running stitch: two shots joined by the marquee itself.  [built: A]
2. Stitched S — the initial S sewn as a running stitch, nothing else.  [built: B]
3. Links — two offset frames interlocking like chain links; overlap = stitched.  [built: C]
4. Zigzag — a tall tile split by a zigzag seam (overlap trim).  (close to 1, less legible small)
5. Stacked brackets — two sets of selection corner brackets one above the other.  (viewfinder cliché)
6. Needle through a frame.  (sewing literalism)
7. Plus tab — a frame with a + tab on its bottom edge ("add below").  (generic)
8. Filmstrip column with sprocket holes as stitch holes.  (film cliché)
9. Shutter S.  (camera cliché, off limits)
10. Ribbon — a strip folding like a receipt with stitches at the folds.  (busy at 16 px)
11. Suture frame — X X X stitches across a cut line in a frame.  (medical reading)
12. Tile evolution — current tile, bars replaced by two frames and a dashed seam.  (variant of 1)
